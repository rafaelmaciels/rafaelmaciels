## Sobre mim

Sou um desenvolvedor com experiência prática na construção de aplicações web de ponta a ponta. Minha jornada na tecnologia passa pelo desenvolvimento de sistemas completos, desde interfaces dinâmicas até APIs robustas e arquitetura de banco de dados. Tenho forte atuação no ecossistema JavaScript/TypeScript e no mundo Java, priorizando sempre um código limpo, padrões arquiteturais bem definidos e performance. Além do desenvolvimento de software, possuo conhecimentos sólidos em infraestrutura de TI, ambientes Linux e manutenção de hardware, o que me proporciona uma visão sistêmica sobre o ciclo de vida das aplicações.

## Projetos em destaque

> ✂️ **Barberflow**
> - **Descrição:** Uma plataforma digital de agendamento e gestão voltada para barbearias.
> - **Tecnologias:** React (Frontend) | PHP & SQL (Backend).
> - **Principais funcionalidades:** Rotas de banco de dados estruturadas, interface dinâmica para o cliente final e painel administrativo para controle eficiente de horários e serviços.

> 🏢 **Cartórium**
> - **Descrição:** Plataforma SaaS Multi-Tenant projetada especificamente para a gestão de cartórios brasileiros.
> - **Principais funcionalidades:** Arquitetura moderna e escalável, focada em otimizar os processos internos e oferecer uma excelente experiência de uso (UX/UI).

> 🏖️ **Pousada**
> - **Descrição:** Sistema desenvolvido para o setor de hotelaria e hospedagem.
> - **Principais funcionalidades:** Interface para gestão de reservas, controle de fluxo de hóspedes e otimização do atendimento local.
